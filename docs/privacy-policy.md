# Gozdar Privacy Policy Draft

## Summary

Gozdar stores forestry workflow data created by the user and uses device services needed for mapping and navigation.

## Data Used by the App

- Location data used to show the user on the map, support navigation, and save field locations when the user triggers those actions
- User-created forestry records such as parcels, logs, notes, and saved locations
- Files generated by the user for export or sharing
- Basic app version information used to identify the installed build

## Data Sharing

Gozdar does not sell personal data. Data created in the app is stored on the device unless the user explicitly exports or shares it.

## Permissions

- Location permissions are used for map centering, compass/navigation workflows, and storing locations selected by the user
- Network access is used to load map tiles, cadastral layers, and release information for non-Play builds

## Retention and Control

Users can delete app data by removing records in the app or uninstalling the app. Exported files are controlled by the user after export.
