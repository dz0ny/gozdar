# flutter_compass (vendored)

Copy of [flutter_compass](https://pub.dev/packages/flutter_compass) 0.8.1
(MIT, see `LICENSE`). Upstream ships only a CocoaPods podspec for iOS; this
copy has a Swift package instead (`ios/flutter_compass/Package.swift`), so the
iOS app builds with Swift Package Manager and no CocoaPods. Dart and Android
code are unchanged.
